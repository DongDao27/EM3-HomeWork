# Bài tập tính hình vuông

Ứng dụng Express theo mô hình MVC, dùng EJS để hiển thị giao diện và MongoDB để lưu kết quả.

## Chạy ứng dụng

1. Đảm bảo MongoDB đang chạy tại `mongodb://127.0.0.1:27017`.
2. Cài thư viện bằng `npm install`.
3. Chạy bằng `npm start`.
4. Mở <http://localhost:3000>.

Dữ liệu được lưu trong database `square_db`, collection `squares`.
