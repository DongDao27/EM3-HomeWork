# Product CRUD - MySQL

Ung dung CRUD san pham theo mo hinh MVC voi Express, EJS va MySQL.

## Chay ung dung

1. Chay file `database.sql` trong MySQL.
2. Sao chep `.env.example` thanh `.env`, sau do sua thong tin ket noi.
3. Chay `npm install`.
4. Chay `npm start`.
5. Mo `http://localhost:3001/products`.

Chuc nang: xem danh sach, them, sua va xoa san pham.
