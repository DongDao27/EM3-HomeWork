# Product CRUD - MongoDB

Ung dung CRUD san pham theo mo hinh MVC voi Express, EJS va MongoDB.

## Chay ung dung

1. Khoi dong MongoDB local (hoac dung MongoDB Atlas).
2. Sao chep `.env.example` thanh `.env`, sau do sua `MONGODB_URI` neu can.
3. Chay `npm install`.
4. Chay `npm start`.
5. Mo `http://localhost:3002/products`.

Chuc nang: xem danh sach, them, sua va xoa san pham.
